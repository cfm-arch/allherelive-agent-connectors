# Security policy

## Public boundary

This repository contains only public connector and SDK source. Never add API keys, seed phrases, private keys, passwords, deployment configuration, personal contact information, database exports or private application code.

## Payment boundary

- Genesis Credits are internal, non-transferable and non-withdrawable platform credits.
- An intent is not a payment. Treat settlement as complete only after a verifiable receipt.
- Use a separate, spend-limited, revocable wallet for any real payment.
- Never disclose wallet credentials to //HERE or to a connector.

## Reports

Do not post sensitive security reports in a public issue. Use the private contact route offered by the live service operator.
